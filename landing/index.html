    Why NeoCloud

    A cloud that stays out of the way.

    🔐

    Encrypted on disk

    Every file is encrypted with its own key before it is written. A stolen drive or a leaked backup shows nothing but noise.

    🪶

    Light and quick

    One small server process and one database file. No PHP stack, no plugin zoo, no weekly update ritual.

    👨‍👩‍👧

    Made for several people

    Everyone gets a private space. Give the family 50 GB each, yourself unlimited, and change it any time.

    🕰️

    Nothing gets lost

    Replacing a file keeps the earlier versions. Deleted things wait in the trash. Uploads resume after a dropped connection.

    How it works

    Up and running in three steps.

    1. 1

      Install it once

      One Docker command or one install script. NeoCloud creates its keys on the first start and runs as a background service.

      docker compose up -d
    2. 2

      Create your account

      The first account becomes the admin. Let the others register, or close sign-up, and set how much space each person gets.

    3. 3

      Drop your files in

      Drag files or whole folders into the browser. Photos, PDFs, Office documents, videos and text open right in the app.

      🖼️ Photos📄 PDF📊 Office🎬 Video📝 Text
    Backups

    A second copy, without a second thought.

    Every night NeoCloud copies what changed to a second place you choose. Only new files travel, old snapshots are pruned on schedule, and the copy is as encrypted as the original.

    • A folder, a USB disk or a NAS share
    • Another machine over SFTP
    • Any S3-compatible bucket: AWS, Backblaze, MinIO, Hetzner
    • A WebDAV share, even an old Nextcloud
    Your NeoCloudnightly · 03:00

    • SFTPoffsite box · ok
    • S3b2 · 7 snapshots
    • WebDAVstorage box · ok
    Security

    Keys all the way down.

    A master key on your server protects one key per person, and each of those protects one key per file. Files are sealed in 64 KB segments, so a video can still be scrubbed and any tampering is caught.

    • Every account sees only its own files
    • Two-step sign-in with an authenticator app
    • Previews are sandboxed, uploads checksummed
    • Open source under the AGPL-3.0 licence
